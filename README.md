# Решения заданий курса Stepik

Решение задания из модуля 3.6 курса [«Автоматизация тестирования с помощью Selenium и Python» на Stepik](https://stepik.org/575): запуск автотестов для разных языков интерфейса с передачей параметра `--language` через командную строку.

## Структура проекта

* `conftest.py` — конфигурация pytest: считывает параметр `--language` и запускает браузер Chrome с выбранной локалью.
* `test_items.py` — тест, проверяющий наличие кнопки добавления товара в корзину на странице товара.
* `requirements.txt` — список необходимых библиотек (`pytest`, `selenium`).

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd <название_папки>
   ```

2. Создайте и активируйте виртуальное окружение (опционально):
   ```bash
   python -m venv venv
   # Windows:
   .\venv\Scripts\Activate.ps1
   # macOS / Linux:
   source venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите тест с нужным языком интерфейса (например, испанским или французским):
   ```bash
   pytest --language=es test_items.py
   pytest --language=fr test_items.py
   ```
